**OmniSnap** is a lightweight, 100% free and open-source browser extension for **Google Chrome, Microsoft Edge, and Brave** that detects and saves embedded videos in original source quality, extracts native audio tracks, and captures high-resolution video frames in one click.

## ✨ Key Features / Características Principales

* **🌐 Multi-Platform Support:** Works seamlessly on **X (Twitter), Reddit (with automatic video + audio merging), TikTok (1080p source quality), Instagram, Pinterest**, forums, and standard HTML5 `<video>` websites.
* **🎞️ Honest Resolution & Format Selector:** Displays the real detected resolution (**`HD 4K`**, **`HD 1080p`**, **`720p`**, **`480p`**), bitrate (`kbps`), or true container format (`MP4`, `WEBM`).
* **⚡ Instant Download Shortcut (`Shift + Click`):** Hold `Shift + Click` on the floating button to immediately download the highest quality available.
* **🎵 Native Audio Extraction (`WAV` / `M4A`):** Uses Chrome's native `Offscreen Audio API` to decode and save audio tracks in seconds.
* **📸 High-Res Frame Capture (`PNG`) & Direct Link Copy.**
* **🏷️ Smart Filenames & True Extensions:** Automatically names files using the author/subreddit, post title, resolution, and real file extension (`.mp4`, `.webm`, `.m4v`, `.m4a`, `.wav`).
* **🌍 9 Languages Built-in:** Auto-detects browser language (**English, Español, Français, Deutsch, Português, Italiano, العربية, 中文, Bahasa Indonesia**).

## 🚀 How to Install (Chrome / Edge / Brave)

1. Download **`OmniSnap-v1.0.0.zip`** from the **[Releases](../../releases)** page and extract it to a folder on your PC.
2. Open your browser and go to `chrome://extensions/` or `edge://extensions/`.
3. Enable **Developer mode**.
4. Click **Load unpacked** (*Cargar descomprimida*) and select the extracted folder.

---

## 🇪🇸 Instrucciones de Instalación en Español

1. Descarga el archivo **`OmniSnap-v1.0.0.zip`** desde la sección **[Releases](../../releases)** y descomprímelo en una carpeta.
2. Abre tu navegador y entra en `chrome://extensions/` (Chrome) o `edge://extensions/` (Edge).
3. Activa el interruptor **Modo de desarrollador** (*Developer mode*).
4. Haz clic en **Cargar descomprimida** (*Load unpacked*) y selecciona la carpeta descomprimida.

## ⚖️ Disclaimer & Privacy

* **Privacy First:** OmniSnap runs 100% locally in your browser. It does **not** collect, store, or transmit any personal data, browsing history, or analytics.
* **Responsible Use:** Intended solely for saving publicly available media that you own or have permission to download for personal offline use.
* **DRM & Protected Platforms:** Encrypted streams and subscription platforms (including YouTube, Netflix, Disney+, Prime Video, Max, and Spotify) are explicitly blocked and unsupported.
